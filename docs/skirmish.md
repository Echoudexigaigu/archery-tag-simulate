# 6v6 对攻模式

入口：`notebooks/03_skirmish_6v6.ipynb`；配置：`configs/skirmish_6v6_23x12.json`。

| 项目 | 模型约定 |
| --- | --- |
| 场地 | 23×12 m，中线 x=11.5 m |
| 玩家 | 红蓝各 6 人，每人 2 命；默认各 2 名老手 |
| 开局装备 | 持弓、空箭；每人三支箭放在中线，全场 36 支 |
| 配额 | 初始箭绑定个人，防止抢走其他人的三箭份额；取走后成为公共可回收资源 |
| 开局解锁 | 到达中线，再实际跑回己方底线才可射击；底线按身体中心 x=0.25 / 22.75 m，判定容差 0.05 m |
| 半场 | 红方身体中心 x∈[0.25,11.25]，蓝方 x∈[11.75,22.75]；玩家半径 0.25 m |
| 掩体中心 | (5.75,3)、(5.75,9)、(17.25,3)、(17.25,9) m；尺寸仍暂定 1×0.6×1 m |
| 复活 | 第一命耗尽后等 3 s，底线空箭复活，保护 0.8 s；越保护线或捡箭提前失效 |
| 开局与复活 | 完成过开局往返后，第二命不必重复；未完成时被击中则重置中线到访标记，复活不能替代跑回底线 |
| 结束 | 一队总剩余命数为零则判负；队员正在等待复活不等于命数耗尽 |
| 平局 | 同一物理 tick 双方全灭，或 120 s 后双方仍有命数 |
| 靶架／接箭 | 本模式无靶架，沿用接箭关闭设置；没有打靶或接箭复活 |

开局配额、半场限制及胜负和平局约定，是对未明确细节的暂定解释，可继续修改。其余物理参数、η 的采样和瞄准／装填／散布映射、奖励数值与之前相同。三箭是开局个人配额，不会在复活时重新生成；射出或掉落的箭仍保留在系统中。

`SkirmishEnvironment` 继承共享的运动、箭矢碰撞和复活实现，通过资源初始化、拾取权限、开局状态更新和终局判定接口修改规则。红队仍用接口键 `attack`，蓝队仍用 `defense`，不代表攻防职责不同。两队使用相同的局部观测策略；动画是全局观察者视角。`get_observation()` 给出 `center_visited`、`shoot_unlocked`、`lives` 和开局箭归属。该接口仍是自定义多智能体接口，并未声称可直接传入 Gym/SB3。

统计必须分开报告红胜、蓝胜、平局，另给非平局样本中的红胜率及 Wilson 区间。大量平局或单一随机种子不能证明规则公平。静态对称地图也不保证某一组个体熟练度或随机误差恰好产生 50% 胜率。
