# 数学模型草案

## 实验对象

以局部观测多智能体环境生成比赛，外层评估规则与靶位。策略好坏与执行能力 eta 分开建模，不能把某个脚本的弱点解释为规则不平衡。

条件 c 包含双方人数、逐人 eta、策略版本与场地几何。规则记为 theta；单块靶架配置记为 Q=(x_r,y_r,psi)，五孔具有固定局部偏移。

$$p_{atk}(theta,Q;c)=P(T_{clear}<=120\mid theta,Q,c).$$

默认超时判守方胜；全歼获胜是另一个规则版本，不混入当前指标。

## 几何与射击

场地为 [0,L]×[0,W]，长度单位米；玩家在地面二维移动，箭矢具有三维位置与速度。靶架是有朝向和高度的平面实体，击落孔的穿透行为由实物确定。

小角度模型下，横向落点误差方差为：

$$Var(e|d,eta_i)=sigma_0^2+d^2 sigma_theta(eta_i)^2.$$

角度误差标准差随熟练度单调降低；瞄准和搭箭时间映射待测。该关系是模型假设，尚未经本场地数据校准。轨迹采样误差后用碰撞判命中，不额外抽一次命中概率。

## 状态与事件

完整状态包含时间、玩家位置/速度/生命/装备/eta/冷却/保护与开局进度、逐支箭的位置与归属、五孔状态、掩体、补给和出生区域。唯一箭矢 ID 保持地面＋携带＋飞行资源守恒。

联合动作同时提交。按最早接触时间处理运动和箭矢碰撞，同刻事件成组结算，避免队伍遍历顺序产生先手优势。具体截止时刻约定待定。

## 靶位约束

靶架必须位于允许区域，不与掩体或入口重叠。每个孔必须从一片非退化、可达且合法的射击区域被看见，不能仅存在一条无法实际利用的射线。

## 平衡目标与验证

$$min_{theta,Q} E_{c~P_eval}[(p_{atk}(theta,Q;c)-0.5)^2].$$

按阵容分层报告，不能仅汇总出 50% 就宣称公平。先固定规则搜索靶位，再研究阵容与简单补偿。搜索场景与最终验证场景分开，交换攻守与物理朝向，使用多个策略和随机种子；配对比赛按配对单位估计不确定性。

主要指标：胜率及置信区间、清靶时间（未完成局保留为未完成/删失，不能当作实际120秒清靶）、截止时剩余孔数、新手参与度、箭矢流向与复活次数。没有运行数据前不发布平衡结论。
